# ดินแดนทดลอง v0.9.8

ข้อมูลจังหวัด/รัฐใช้เป็นหน่วยดินแดนเท่านั้น ไม่มีการก่อสร้าง คิว ระดับความเจริญ หรือสูตรความสุขรายจังหวัด รายได้และความสุขคำนวณระดับประเทศตามระบบเดิม

## ข้อมูลชุดเดียว

`data/provinces/index.json` (25,709 ไบต์) เป็น metadata ชุดเดียว 226 เขต แต่ละเขตมีเพียง `id`, `nameTh`, `owner`, `share`, `resourceId`, `borders` ไฟล์ GeoJSON แยกประเทศเก็บ geometry และ id สำหรับจับคู่เท่านั้น เมื่อโหลดจะใช้ properties อ้างอิงจาก index ชุดเดียวกัน ไม่มีรายชื่อ/ตัวเลขจังหวัดซ้ำอีกชุด

| ประเทศ | เขต | ไฟล์เส้น | ขนาดไบต์ |
|---|---:|---|---:|
| ไทย | 76 | th.json | 134330 |
| จีน | 31 | cn.json | 280244 |
| สหรัฐฯ | 50 | us.json | 250425 |
| ญี่ปุ่น | 47 | jp.json | 119867 |
| ฝรั่งเศส | 22 | fr.json | 90720 |

`share` เป็นเปอร์เซ็นต์จากสัดส่วนประชากรสำมะโนใกล้ปี 2000 ที่ใช้ใน v0.9.7 ปัดเป็นหน่วย 0.01% ด้วยวิธีแจกเศษมากที่สุด รวมประเทศละ 100.00% ใช้สัดส่วนเดียวกันแบ่งรายรับภาษี ประชากร และผลผลิต ไม่อ้างว่าแต่ละจังหวัดสร้างรายได้จริงตามเปอร์เซ็นต์นี้ ทรัพยากรเด่นเป็นการจัดประเภทภูมิศาสตร์โดยประมาณ ไม่ใช่ปริมาณสำรองจริง

`owner` ในไฟล์คือประเทศต้นทางปี 2000 ผู้ครองปัจจุบันใช้ `provinceOwner(state, province)` ซึ่งอ่าน override จากเซฟ สัดส่วนต้นทางไม่เปลี่ยนเมื่อโอนดินแดน

## แผนที่และเขตแดน

แหล่งเส้น: [Natural Earth Admin-1 1:10m](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/) เป็น [public domain](https://www.naturalearthdata.com/about/terms-of-use/) และ [GeoJSON ต้นฉบับ](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson)

- ไทยรวมบึงกาฬกลับหนองคายเป็น 76 จังหวัดตามปี 2000
- ฝรั่งเศสรวม 96 départements เป็น 22 แคว้นก่อนปี 2016 ไม่รวมโพ้นทะเล รหัส FR-Rxx อ้างเลขแคว้นเดิม
- สหรัฐฯ 50 รัฐ ไม่รวม ดี.ซี. เป็นรัฐ จีนไม่รวมไต้หวัน ฮ่องกง มาเก๊า ญี่ปุ่น 47 จังหวัด
- ย่อขอบร่วมด้วย Shapely coverage_simplify แล้วลดความละเอียดพิกัด เส้นร่วมไม่แยกเป็นรอยว่าง ตรวจ geometry valid และไม่เกิน 300,000 ไบต์ต่อไฟล์
- `borders` มาจากแนวที่ติดเขต Admin-1 ของประเทศอื่นใน Natural Earth ใช้ระยะเผื่อพิกัด 0.002 องศา ไม่รวมการอยู่คนละฝั่งทะเล เช่น ญี่ปุ่นไม่มีเพื่อนบ้านทางบก ไทยเชียงใหม่ติด MMR อยุธยาไม่ติดประเทศอื่น
- ข้อมูล Natural Earth รุ่นปัจจุบันปรับรวมหน่วยบริหารให้ใกล้ปี 2000 ไม่ใช่แผนที่สำรวจแนวเขตทุกจุดในปี 2000 ข้อพิพาท/ชายฝั่งยึดการแสดงข้อมูลต้นทาง และอาจต่างจากแผนที่ประเทศ 1:50m เล็กน้อย

แหล่งน้ำหนักประชากรเดิม: [US Census 2000](https://www2.census.gov/programs-surveys/decennial/tables/2000/2000-quick-facts/tab04.pdf), [จีน Census 2000](https://www.stats.gov.cn/english/NewsEvents/200204/t20020423_25982.html), [ญี่ปุ่น Census](https://www.stat.go.jp/english/data/kokusei/index.htm), [ฝรั่งเศส Census 1999 มีผลปี 2000](https://www.legifrance.gouv.fr/loda/id/JORFTEXT000000398186/), ตารางรวบรวม [ไทย](https://www.citypopulation.de/en/thailand/admin/), [จีน](https://www.citypopulation.de/en/china/admin/), [ญี่ปุ่น](https://www.citypopulation.de/en/japan/admin/)

## ฟังก์ชันสำหรับรอบสงคราม

```js
import {createTerritoryController} from './js/territories.js';
const {transferProvince} = createTerritoryController(state, catalog);
transferProvince('TH-50', 'MMR');
```

หรือเรียก export `transferProvince(state, catalog, provinceId, newOwner)` โดยตรง ไม่สร้างระบบสงครามหรือปุ่มโอนใน UI

- รายรับภาษี = ฐานรายรับประเทศ × share ที่เหลือ + ส่วนรายรับจากฐานประเทศต้นทางของดินแดนที่ได้เพิ่ม สูตรภาษี/นโยบาย/ระบอบเดิมยังใช้ต่อ GDP ภายในเป็นฐานคำนวณเดิม ไม่ตัด GDP ซ้ำทุกเดือน
- ประชากรโอนเป็นจำนวนคนและแจกเศษอย่างอนุรักษ์ยอดรวม ผลผลิตทรัพยากรแบ่งจากฐานของแต่ละประเทศก่อนส่งออก แจกเศษจำนวนเต็มโดยไม่สร้างทรัพยากรเพิ่ม คลังที่สะสมแล้วไม่ถูกย้าย
- โอนกลับเจ้าของเดิมแล้วลบ override ไม่มีผลซ้ำเมื่อโอนไปเจ้าของเดิมซ้ำ
- X/Y ในแผงประเทศนับเขตที่ครองเทียบเขตต้นทางและเขตที่ได้เพิ่ม เปอร์เซ็นต์เป็น share ที่ยังครองเทียบฐานพื้นที่ชุดนั้น ประเทศนอก 5 ประเทศไม่มีโหมดเขต เว้นแต่ได้ดินแดนจาก 5 ประเทศผ่านฟังก์ชันนี้
- เซฟใหม่เก็บ `territories.owners` เฉพาะที่เปลี่ยน และฐานประชากรเฉพาะประเทศที่เกี่ยวข้องกับการโอน

## เหตุการณ์และประสิทธิภาพ

`data/events-province.json` มีน้ำท่วมภาคกลางไทย แผ่นดินไหวญี่ปุ่น/เขตรอยเลื่อนจีน พายุในพื้นที่เสี่ยง น้ำท่วมฝรั่งเศส แร่ ความไม่สงบ และข้อพิพาทชายแดน สุ่มไม่เกินเดือนละหนึ่งเรื่อง มี cooldown ต่อเหตุการณ์/พื้นที่ ภัยพิบัติลดผลผลิตพื้นที่ชั่วคราวหรือใช้เงินฟื้นฟู แร่เพิ่มคลังจริง ความไม่สงบที่เลือกปล่อยไว้อย่างน้อย 6 เดือนลดความสุขและอาจย้ายจังหวัดชายแดนไปอยู่กับเพื่อนบ้าน (หรือกลับประเทศต้นทางหากถูกยึด) พื้นที่ภายในไม่สร้างประเทศสมมติ

ข้อพิพาทมี 3 ปุ่มที่ใช้ได้: เจรจา / จ่ายเงิน / ยอมเสียดินแดน และข้อความตัวเลือกใช้กำลังสีเทาซึ่งยังไม่เปิด ข่าวและจุดเตือนกดซูมได้ หน้าตัดสินใจไม่ปิดกั้นการแตะแผนที่ เวลาหยุดตามเงื่อนไข dialog เดิม ไม่มีการแก้ js/time.js, js/ui/time-screen.js หรือ data/balance.json

เส้นซ่อนต่ำกว่า 3× เตรียม Path2D ครั้งเดียว คุณภาพกลาง/ต่ำรวมสีผู้ครองและเส้นลงภาพชั้นสีเดิม แอนิเมชันจุดเตือนใช้ opacity ของ CSS ปิดตามโหมดประหยัด/ลดการเคลื่อนไหว ไม่มีวงรอบวาดใหม่เพิ่ม โหลดเส้นเฉพาะประเทศผู้เล่นและประเทศต้นทางของดินแดนที่ได้เพิ่ม แคช network-first เมื่อโหลดแล้วเพื่อเล่นออฟไลน์

ทดสอบ Chromium จำลองแท็บเล็ต CPU throttle 4× ฉากจีนซูม 8× คุณภาพกลาง 130 เฟรมหลังอุ่นเครื่อง: 1280×800 DPR 1.5 ก่อน/หลัง 18→18 FPS, 1112×834 DPR 2 ก่อน/หลัง 19→19 FPS ไม่ใช่ผลบน Tab S6 Lite/iPad Air 3 จริง และไม่ได้ทดสอบ Safari/WebKit

## ลบระบบเก่าและสร้างข้อมูลซ้ำ

ลบ js/provinces.js, js/data/province-migration.js, js/ui/province-screen.js, css/provinces.css, data/provinces/config.json และสคริปต์/ข้อมูลเตรียมระบบบริหารเก่า แทนการซ่อน UI เซฟเก่าที่มี `state.provinces` ถูกข้ามและตัดออกเมื่อบันทึกใหม่ เงิน คลัง ยูนิต วันที่ และคิวผลิตกองทัพยังอยู่ตามเดิม ไม่เดินคิวก่อสร้าง ไม่คืนหรือหักค่าก่อสร้างซ้ำ

สร้างเส้น/เพื่อนบ้านซ้ำด้วย `python tools/build-territory-maps.py <ne_10m_admin_1_states_provinces.geojson>` ใช้ Python + Shapely >= 2.1 เฉพาะเตรียมข้อมูล อ่าน metadata canonical จาก index และข้อมูลรวมเขตจาก tools/territory-groups.json ไม่อ่านข้อมูลบริหารจาก commit เก่า ไม่ใช้ Python/npm ตอนเล่น
