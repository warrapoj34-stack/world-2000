ดาวน์โหลดและสกัดข้อมูลวันที่ 2026-11-06 ไม่มีการโหลดข้อมูลภายนอกตอนรันเกม

## สถิติประเทศและสถานการณ์ v0.3.0

`countries_2000.json` ครอบคลุม 237 หน่วยแสดงผลบนแผนที่ มี `mapId` เชื่อมรหัสแผนที่เดิมกับ `id` สามตัวของประเทศ จัด 191 ประเทศให้สุ่มเกิดได้ ดินแดนและเขตบริหารพิเศษอื่นดูข้อมูลได้แต่ไม่อยู่ในชุดสุ่ม

### ตัวเลขอ้างอิง

ดาวน์โหลด World Bank API วันที่ 2026-11-06 โดยระบุ `date=2000` และ `per_page=400` เก็บผลดิบใน `data/sources/`:

- GDP ราคาปัจจุบันสกุลดอลลาร์: https://api.worldbank.org/v2/country/all/indicator/NY.GDP.MKTP.CD?date=2000&format=json&per_page=400
- ประชากร: https://api.worldbank.org/v2/country/all/indicator/SP.POP.TOTL?date=2000&format=json&per_page=400
- รายจ่ายทหาร ดอลลาร์ปัจจุบัน: https://api.worldbank.org/v2/country/all/indicator/MS.MIL.XPND.CD?date=2000&format=json&per_page=400 (World Bank เผยแพร่ข้อมูลที่มาจาก SIPRI)
- ฐานข้อมูลและวิธีวิจัย SIPRI: https://www.sipri.org/databases/milex และ https://www.sipri.org/databases/milex/sources-and-methods
- มีไฟล์หนี้รัฐบาลกลาง `GC.DOD.TOTL.GD.ZS` เก็บไว้ประกอบการตรวจ แต่ไม่ได้ใช้ตรง ๆ เพราะขอบเขตหนี้รัฐบาลกลางไม่เท่าหนี้สาธารณะรวม
- ข้อกำหนดการใช้ World Bank: https://www.worldbank.org/en/about/legal/terms-of-use-for-datasets — อ้างอิง World Bank WDI และผู้ให้ข้อมูลต้นทาง

ใช้ค่ารายปี 2000 เป็นภาพตั้งต้นของเกมที่แสดงเดือนมกราคม ไม่ใช่สถิติที่วัดเฉพาะวันที่ 1 มกราคม หากมีการแก้ไขย้อนหลังในฐานข้อมูล ตัวเลขอาจต่างจากสิ่งพิมพ์เดิมในปีนั้น ตัวอย่างชุดที่ดาวน์โหลด: USA GDP 10,250.952 พันล้านดอลลาร์, CHN GDP 1,223.755 พันล้านดอลลาร์และประชากร 1,262.645 ล้านคน, THA GDP 126.392 พันล้านดอลลาร์

ทุกประเทศมี `provenance` ระบุว่า GDP/ประชากรเป็น `world_bank_2000` หรือ `scenario_estimate` รายการที่ขาด เช่น GDP เกาหลีเหนือ ไต้หวัน และเกาะขนาดเล็ก ใช้ประมาณการที่อยู่ใน `country-generation-2000.json` ไม่อ้างว่าเป็นข้อมูล World Bank

ซูดานรวมประชากร SDN+SSD ให้ตรงพื้นที่รวม ส่วน GDP ใช้อนุกรม SDN เป็นค่าประมาณของขอบเขตเดิมและติดป้าย estimate ยูโกสลาเวียใช้ GDP SRB+MNE บวกประมาณการโคโซโว และประชากรรวมทั้งสามส่วน ติดป้าย estimate เช่นกัน

### ค่าประเมินสำหรับเกม

- `treasury`: เงินตั้งต้นสำหรับเกม ไม่ใช่ยอดบัญชีคลังจริง ใช้ 12% ของ GDP หรือ 8% สำหรับกลุ่มสถานการณ์ไม่มั่นคง
- `debt`: ประมาณการหนี้สาธารณะคิดเป็น % GDP ไม่ใช่การนำอนุกรมรัฐบาลกลางของ World Bank มาอ้างว่าเทียบกันได้ทุกประเทศ
- `military`: ดัชนีเกม 0–100 ประเมินจากลอการิทึมรายจ่ายทหาร SIPRI/World Bank และปรับประเทศสำคัญด้วยมือ เช่น สหรัฐ 100 รัสเซีย 92 จีน 88 เกาหลีเหนือ 80 ไม่ใช่คะแนนที่ SIPRI เผยแพร่
- `stability`, `happiness`, `tech`, `reputation`, `resources`: ค่าประเมินเชิงสถานการณ์เพื่อเล่นเกม ไม่ใช่การสำรวจประชากรหรือค่าทางสถิติจริง ชุดประเทศสำคัญปรับเป็นรายประเทศ ที่เหลือใช้ระดับรายได้และกลุ่มทรัพยากรโดยประมาณ
- `government`: จัดระบอบคร่าว ๆ ตามสถานการณ์ต้นปี 2000 ให้อยู่ใน 5 หมวดที่โจทย์กำหนด ไม่จำลองรายละเอียดระบบผสมทั้งหมด ดินแดนใช้หมวดของการบริหารโดยประมาณ ติมอร์-เลสเตและพื้นที่ไร้รัฐบาลประจำมี `governmentLabelTh` แสดงคำอธิบายที่เหมาะสมแทนชื่อระบอบ
- ไม่มีบุคคลจริงในข้อมูล ผู้เล่นรับบทประเทศเท่านั้น

### รหัสประเทศ

ใช้ ISO alpha-3 ปัจจุบันเพื่อเชื่อมข้อมูล เช่น `TLS` แม้ปี 2000 ยังอยู่ภายใต้ UN และ `YUG` เป็นรหัสประวัติศาสตร์ของยูโกสลาเวีย ดินแดน 4 แห่งไม่มีรหัส ISO alpha-3 จึงใช้รหัสเฉพาะ `XSL`, `XNC`, `XIO`, `XSG` พร้อม `idType: custom` ไม่อ้างว่าเป็นรหัส ISO ที่ได้รับมอบหมาย

`iso-mappings.json` มาจาก CLDR 46.1.0 เช่นเดียวกับชื่อไทย โดยเลือกเฉพาะ territory code สองตัวและแก้ alias เก่า ZAR/TMP ให้เป็น COD/TLS ไม่ใช้ currency code ที่บังเอิญมี numeric code เดียวกัน

### ความสัมพันธ์

`relations_2000.json` เป็นคะแนนสถานการณ์สมมาตรระหว่างคู่ประเทศ ไม่ใช่ดัชนีทางสถิติ คู่อื่นเป็น 0 คู่ที่ระบุทับคะแนนกลุ่มได้ เช่น กรีซ–ตุรกี แม้เป็นสมาชิก NATO เหมือนกัน

- NATO ใช้ 19 ประเทศในปี 2000: https://nato.int/en/what-we-do/partnerships-and-cooperation/enlargement-and-article-10
- อาเซียนใช้ 10 ประเทศหลังรับกัมพูชาในปี 1999: https://asean.org/asean-milestone/
- ไม่ใส่ประเทศที่เข้าร่วมภายหลังเป็นสมาชิกย้อนหลัง

สูตรสร้างข้อมูลอยู่ใน `tools/generate-countries.py` ค่าปรับและชื่อประเทศอยู่ใน `data/country-generation-2000.json` ไฟล์อ้างอิงและเครื่องมือเหล่านี้ไม่ถูกโหลดระหว่างเล่น
