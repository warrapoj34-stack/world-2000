# World 2000

เกม 2D grand strategy โทน casual ผู้เล่นรับบทเป็นประเทศจริงในปี ค.ศ. 2000
รุ่น v0.2.0 กด “เริ่มเกมใหม่” เพื่อสำรวจแผนที่โลกปี 2000 ได้แล้ว ส่วน “เล่นต่อ” ยังปิดใช้งาน ยังไม่มีระบบบริหารประเทศหรือบันทึกเกม

## เปิดโปรเจกต์

ไม่ต้อง build และไม่ต้องใช้ npm ให้เสิร์ฟโฟลเดอร์นี้ผ่าน HTTP เช่น หากมี Python:

```sh
python -m http.server 8000
```

เปิด `http://localhost:8000` (การเปิด `index.html` ผ่าน `file://` ไม่รองรับ ES modules และ service worker)

สำหรับ GitHub Pages ตั้ง Settings → Pages → Deploy from a branch แล้วเลือก branch ที่มีไฟล์ชุดนี้และโฟลเดอร์ `/ (root)` เส้นทางทุกไฟล์รองรับ `/world-2000/` มี `.nojekyll` เพื่อเสิร์ฟไฟล์แบบ static

## PWA และการอัปเดต

- ใช้ HTTPS บน GitHub Pages หรือ localhost สำหรับพัฒนา
- เปิดออนไลน์สำเร็จครั้งแรกและรอข้อความ “พร้อมใช้งานแบบออฟไลน์” ก่อนเปิดแบบออฟไลน์
- service worker ลองโหลดเครือข่ายก่อนทุกครั้ง โดยไม่ใช้ HTTP cache หากเครือข่ายล้มเหลว ตอบสถานะผิดพลาด หรือรอนานเกิน 4 วินาที จะใช้ไฟล์ที่แคชไว้
- เปลี่ยนเวอร์ชันใน `js/version.js` พร้อมบันทึก `CHANGELOG.md` ทุกชุดงาน เมื่อ worker ใหม่แคชไฟล์ครบจะเปิดใช้งาน ล้างแคชเกมรุ่นเก่า และรีโหลดหน้าที่ถูกควบคุมอยู่
- ตรวจอัปเดตเมื่อเปิดหน้า กลับมาที่แอป หรือกลับมาออนไลน์ การเห็นไฟล์ใหม่ยังขึ้นกับการเผยแพร่และแคชฝั่งโฮสต์ด้วย
- เมื่อเพิ่มทรัพยากรที่ต้องใช้แบบออฟไลน์ ให้เพิ่มรายการใน `APP_SHELL` ของ `sw.js`
- บน Chrome Android ใช้เมนูติดตั้งแอป/เพิ่มลงหน้าจอหลัก เล่นแนวนอนเป็นหลัก

โหมดออฟไลน์เปิดได้ทั้งเมนูและแผนที่ รวมถึงการเลือกประเทศ โดยต้องแคชเสร็จจากการเปิดออนไลน์ก่อน

## แผนที่และการควบคุม

- Canvas วาดรูปทรงด้วย d3 และเก็บ Path2D ใช้ซ้ำ วาดเมื่อมีการเปลี่ยนแปลงผ่าน requestAnimationFrame จำกัดความละเอียดที่ 2 เท่าของ CSS pixels
- ลากด้วยนิ้ว/เมาส์ กางหรือหุบสองนิ้วเพื่อซูม และใช้ล้อเมาส์ได้ ซูมระหว่าง 1–12 เท่าของมุมมองทั้งโลก
- การเคลื่อนไหวน้อยกว่า 10 CSS pixels เป็นการแตะ ระยะตั้งแต่ 10 pixels เป็นการลาก การซูมสองนิ้วหรือ pointercancel ไม่เลือกประเทศ
- แตะประเทศเพื่อไฮไลต์และแสดงชื่อไทย หรือเลือกจากรายชื่อด้านข้างเพื่อดูประเทศเล็ก ๆ
- คีย์บอร์ด: โฟกัสแผนที่แล้วใช้ลูกศรเลื่อน, +/− ซูม, Home ดูทั้งโลก, Escape ยกเลิกการเลือก
- พรมแดนที่รวมใช้รูปทรงเดียว ไม่มีเส้นแบ่งซูดานใต้หรือเส้นภายในยูโกสลาเวีย ส่วนติมอร์-เลสเตใช้สีเทา
- การปรับประวัติศาสตร์ครอบคลุมรายการที่กำหนดในรอบนี้ พื้นที่อื่นยังใช้รูปทรง Natural Earth ต้นทาง

## ตรวจข้อมูลสำหรับผู้พัฒนา

ถ้ามี Node.js รุ่นที่รองรับ ES modules ในไฟล์ `.js` รันได้โดยไม่ต้องติดตั้งแพ็กเกจ:

```sh
node --test tests/world.test.mjs
```

การรันเกมไม่ต้องใช้ Node.js การตรวจบนอุปกรณ์จริงยังควรทดสอบแยกจากเบราว์เซอร์จำลอง
