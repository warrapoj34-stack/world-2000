# World 2000

เกม 2D grand strategy โทน casual ผู้เล่นรับบทเป็นประเทศจริงในปี ค.ศ. 2000
รุ่น v0.5.0 เพิ่มทรัพยากร 12 ชนิด ผลผลิตรายเทิร์นและโหมดสีแผนที่ พร้อมเมนู 6 หมวด บทแนะนำ และเซฟเดิมที่ยังเล่นต่อได้

เปิด **ทรัพยากร** เพื่อดูดาวและผลผลิต แตะการ์ดเพื่อดูประโยชน์ จบเทิร์นเพื่อรับผลผลิต เหล็กในคลังใช้ร่วมกับเงินเพื่อเสริมกำลังทหารได้ เปลี่ยน **โหมดแผนที่** มุมขวาบนเพื่อเปรียบเทียบทรัพยากร 0–5 ดาว เลือกประเทศเพื่อดูทรัพยากรเด่นสามชนิด รายได้จากทรัพยากรและภัยแล้งดูได้ในรายละเอียดรายงานท้ายเทิร์น

ข้อมูลดาวและราคาสินค้าเป็นค่าประมาณ/หน่วยเกม อ่านที่มาและข้อจำกัดใน `data/RESOURCE_SOURCES.md` สูตรอยู่ใน `js/resources.js` ค่าปรับสมดุลอยู่ใน `data/balance.json` เซฟเดิมเริ่มคลังว่าง ไม่มีการเพิ่มผลผลิตย้อนหลัง

## วิธีเล่น

1. เริ่มเกมใหม่ → สุ่มประเทศ → รับตำแหน่ง (หรือเล่นต่อจากเซฟเดิม)
2. กด **นโยบาย** ปรับภาษีและงบห้าหมวด งบรวม 100% อัตโนมัติ ดูประมาณการก่อนตัดสินใจ
3. กด **จบเทิร์น +3 เดือน** มุมขวาล่าง อ่านรายงานผล สีเขียวคือดีขึ้น สีแดงคือแย่ลง
4. เปิด **ประเทศ → อันดับโลก** เพื่อเทียบขนาดเศรษฐกิจ หนี้เกิน 200% หรือความมั่นคง 0 จะจบเกม

แตะหรือกดค้างที่รูปบนแถบค่าหลักเพื่ออ่านคำอธิบาย เปิดบทแนะนำซ้ำหรือแสดงภารกิจที่ซ่อนไว้ได้ในหน้า **ประเทศ** รายงานหลังจบเทิร์นแสดงสรุปสั้น กด **ดูรายละเอียด** เพื่ออ่านตัวเลขทั้งหมด ตลาดและระบบสร้างเส้นทางยังเป็นหน้า **เร็วๆ นี้** ค่าการซ่อนคำแนะนำเก็บแยกใน `world-2000:ui-preferences` ไม่เปลี่ยนเซฟประเทศ

GDP เป็นรายปี รายรับต่อไตรมาส = GDP × ภาษี ÷ 4 งบพื้นฐาน = GDP × 25% ÷ 4 ปรับต้นทุนทหารตามระบอบ บวกดอกเบี้ยหนี้ ใช้เงินคลังก่อนกู้ส่วนที่ขาด หนี้แสดงเป็น % ของ GDP ใหม่ เงินเกินเก็บในคลัง ไม่มีการชำระหนี้อัตโนมัติในรุ่นนี้

สูตรเกมอยู่ใน `js/economy.js` และค่าทั้งหมดอยู่ใน `data/balance.json` เป็นแบบจำลองสำหรับเกม ไม่ใช่การพยากรณ์เศรษฐกิจจริง ประเทศ AI ใช้นโยบายตั้งต้นเดียวกันแต่ผลขึ้นกับสถิติและระบอบของตนเอง เซฟรุ่นก่อนจะได้รับนโยบายตั้งต้นเมื่อเล่นต่อ

## เปิดโปรเจกต์

ไม่ต้อง build และไม่ต้องใช้ npm ให้เสิร์ฟโฟลเดอร์นี้ผ่าน HTTP เช่น หากมี Python:

```sh
python -m http.server 8000
```

เปิด `http://localhost:8000` (การเปิด `index.html` ผ่าน `file://` ไม่รองรับ ES modules และ service worker)

สำหรับ GitHub Pages ตั้ง Settings → Pages → Source เป็น GitHub Actions แล้วใช้ workflow `Publish World 2000` ใน `.github/workflows/pages.yml` ซึ่งทำงานเมื่อ push ไป main หรือสั่ง workflow_dispatch โดยตรวจข้อมูลและเซฟก่อนคัดลอกไฟล์ static ไป `_site/` เพื่อเผยแพร่ เส้นทางทุกไฟล์รองรับ `/world-2000/` มี `.nojekyll` เพื่อเสิร์ฟไฟล์แบบ static การเล่นและพัฒนาในเครื่องยังไม่ต้องทำขั้นตอนนี้

หากเว็บแสดงรุ่นเก่า ให้ตรวจผลขั้น Deploy ใน Actions และเทียบ `js/version.js` กับ `release.json` บนเว็บจริง การ push สำเร็จเพียงอย่างเดียวยังไม่ยืนยันว่า Pages เผยแพร่สำเร็จ

## PWA และการอัปเดต

- ใช้ HTTPS บน GitHub Pages หรือ localhost สำหรับพัฒนา
- เปิดออนไลน์สำเร็จครั้งแรกและรอข้อความ “พร้อมใช้งานแบบออฟไลน์” ก่อนเปิดแบบออฟไลน์
- service worker ลองโหลดเครือข่ายก่อนทุกครั้ง โดยไม่ใช้ HTTP cache หากเครือข่ายล้มเหลว ตอบสถานะผิดพลาด หรือรอนานเกิน 4 วินาที จะใช้ไฟล์ที่แคชไว้
- เปลี่ยนเวอร์ชันใน `js/version.js` พร้อมบันทึก `CHANGELOG.md` ทุกชุดงาน เมื่อ worker ใหม่แคชไฟล์ครบจะเปิดใช้งาน ล้างแคชเกมรุ่นเก่า และรีโหลดหน้าที่ถูกควบคุมอยู่
- ตรวจอัปเดตเมื่อเปิดหน้า กลับมาที่แอป หรือกลับมาออนไลน์ การเห็นไฟล์ใหม่ยังขึ้นกับการเผยแพร่และแคชฝั่งโฮสต์ด้วย
- เมื่อเพิ่มทรัพยากรที่ต้องใช้แบบออฟไลน์ ให้เพิ่มรายการใน `APP_SHELL` ของ `sw.js`
- บน Chrome Android ใช้เมนูติดตั้งแอป/เพิ่มลงหน้าจอหลัก เล่นแนวนอนเป็นหลัก

โหมดออฟไลน์เปิดได้ทั้งเมนูและแผนที่ รวมถึงการเลือกประเทศ โดยต้องแคชเสร็จจากการเปิดออนไลน์ก่อน

## เริ่มเกมและเซฟ

- เริ่มเกมใหม่สุ่มจาก 191 ประเทศที่เล่นได้ ประเทศและดินแดนทั้งหมดบนแผนที่ยังมีข้อมูลครบ 237 รายการ
- สุ่มใหม่ได้ 3 ครั้งต่อฉบับร่าง เก็บผลและจำนวนครั้งก่อนเริ่มแอนิเมชัน การรีเฟรชจึงไม่เพิ่มสิทธิ์สุ่ม
- “เลือกประเทศเอง” เป็นโหมดทดสอบ เลือกได้จากประเทศที่เล่นได้โดยไม่ใช้สิทธิ์สุ่ม
- เมื่อกด “รับตำแหน่ง” จะสร้างเกมเดือนมกราคม 2000 และบันทึกอัตโนมัติ ประเทศผู้เล่นมีขอบเรืองแสงสีเขียวอ่อน
- การเลือกประเทศ เลื่อน/ซูม กลับเมนู ซ่อนหน้า หรือออกจากหน้า จะบันทึกสถานะเกม มุมมอง และสถิติปัจจุบันด้วย
- ปุ่ม “เล่นต่อ” เปิดเกมที่บันทึกไว้ หากยังไม่มีเกมจะเปิดฉบับร่างที่สุ่มค้างไว้
- ใช้ localStorage key `world-2000:game` และ `world-2000:draft` แยกกัน ฉบับร่างใหม่ไม่ทับเกมเดิมจนกดรับตำแหน่ง
- โครงเซฟมี `saveVersion: 1`, `gameVersion`, `savedAt`, `kind`, `state` การเปลี่ยนเวอร์ชันแอปไม่ทำให้เซฟหาย
- เซฟผิดรูปแบบหรือรุ่นอนาคตจะถูกแจ้งและเก็บไว้ ไม่ลบโดยอัตโนมัติ หาก storage ถูกปิด/เต็ม จะแจ้งว่าบันทึกไม่ได้และเล่นต่อในหน้านั้นได้
- เซฟอยู่ในเบราว์เซอร์และ origin นี้เท่านั้น การล้างข้อมูลเว็บไซต์จะลบเซฟ และไม่มีการซิงก์ข้ามอุปกรณ์
- ข้อมูล GDP/เงินคลังใช้พันล้านดอลลาร์ ประชากรใช้ล้านคน คะแนน 0–100 เป็นค่าประเมินสำหรับเกม ดูวิธีคำนวณและข้อจำกัดใน `data/SOURCES.md`

## แผนที่และการควบคุม

- Canvas วาดรูปทรงด้วย d3 และเก็บ Path2D ใช้ซ้ำ วาดเมื่อมีการเปลี่ยนแปลงผ่าน requestAnimationFrame จำกัดความละเอียดที่ 2 เท่าของ CSS pixels
- ลากด้วยนิ้ว/เมาส์ กางหรือหุบสองนิ้วเพื่อซูม และใช้ล้อเมาส์ได้ ซูมระหว่าง 1–12 เท่าของมุมมองทั้งโลก
- การเคลื่อนไหวน้อยกว่า 10 CSS pixels เป็นการแตะ ระยะตั้งแต่ 10 pixels เป็นการลาก การซูมสองนิ้วหรือ pointercancel ไม่เลือกประเทศ
- แตะประเทศเพื่อไฮไลต์และแสดงชื่อไทย หรือเลือกจากรายชื่อด้านข้างเพื่อดูประเทศเล็ก ๆ
- คีย์บอร์ด: โฟกัสแผนที่แล้วใช้ลูกศรเลื่อน, +/− ซูม, Home ดูทั้งโลก, Escape ยกเลิกการเลือก
- พรมแดนที่รวมใช้รูปทรงเดียว ไม่มีเส้นแบ่งซูดานใต้หรือเส้นภายในยูโกสลาเวีย ส่วนติมอร์-เลสเตใช้สีเทา
- การปรับประวัติศาสตร์ครอบคลุมรายการที่กำหนดในรอบนี้ พื้นที่อื่นยังใช้รูปทรง Natural Earth ต้นทาง

## ตรวจข้อมูลสำหรับผู้พัฒนา

ถ้ามี Node.js รุ่นที่รองรับ ES modules ในไฟล์ `.js` รันได้โดยไม่ต้องติดตั้งแพ็กเกจ:

```sh
node --test tests/world.test.mjs tests/game.test.mjs
```

การรันเกมไม่ต้องใช้ Node.js การตรวจบนอุปกรณ์จริงยังควรทดสอบแยกจากเบราว์เซอร์จำลอง

หากต้องการสร้าง `countries_2000.json` ใหม่จากไฟล์อ้างอิงที่เก็บไว้ ใช้ `python tools/generate-countries.py` โดยปรับค่าประเมินใน `data/country-generation-2000.json` ก่อน ไม่ต้องดาวน์โหลดใหม่และไม่ใช่ขั้นตอนก่อนเล่น
